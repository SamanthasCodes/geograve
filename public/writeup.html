GEOGRAVE

GEOGRAVE shows how bird abundance changes across space and time for selected species, and how those patterns differ across regions and seasons. The interaction design is intentionally narrow due to the size of the data files.

We start with species search and a species card so users can identify the correct bird and learn its scientific name, then we move to a globe view and animated weekly abundance points, so users can move from identification to geographic context to temporal change without being overwhelmed.

The search box and info card provide fast details on demand and reduce the dataset to one species at a time. The globe gives geographic context, while the timeline and weekly animation show seasonal movement and change over time, and the regional chart summarizes bird population distribution.

The data processing was also necessary to make this possible in the browser, since the raw files were too large and were converted into 832 weekly JSON data files with geographic coordinates.

Data Sources

The main data source is eBird Status & Trends , with supporting biome geometry and species metadata copied into the static site during preprocessing.

Development Process

We developed the project in phases:

  1. Designed the layout and collected the data
  2. Preprocessed the data
  3. Built the globe visualization shell
  4. Implemented the species search and information card
  5. Added the timeline and weekly abundance animation
  6. Performed a projection correction pass to restore geographic accuracy

Technical Challenges

The hardest part of the project was preprocessing the data and ensuring consistency across the datasets. The original files were extremely large and required substantial restructuring before they could be visualized efficiently in the browser.

During implementation, we also discovered that the coordinate projections were not in the correct format for GeoJSON rendering. Considerable time was spent diagnosing and correcting the issue.

The projection correction was based on the eBird documentation and the Equal Earth projection reference. This correction restored geographic placement accuracy without requiring changes to the rendering pipeline.
